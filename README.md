# COIN BOARD

최종 업데이트: 2026-08-11

**🔗 https://purplusnow.github.io/coinboard/**

업비트의 가격 변동을 **글로벌 성분과 국내 성분으로 분해**해 실시간 전광판으로 보여주는
GitHub Pages 정적 사이트. 서버 없음, API 키 없음, 비용 0원.

```
업비트 원화 수익률 = (1 + 바이낸스 USDT 수익률)(1 + USDT/원 수익률) − 1  +  국내 성분
                     └────────── 글로벌 성분 ──────────┘
```

업비트 앱에서 `+0.89%`로만 보이는 코인이, 실제로는 글로벌에서 `−0.38%` 하락 중인데
국내에서만 `+1.27%p` 밀어올린 것일 수 있다. 이 구분은 두 거래소를 동시에 봐야 나오고,
어느 거래소 앱에도 없다.

검정 규약: 정보계수(IC) · 시장 중립화 · 비중첩 표본 · **GAP 검정**(신호와 수익률 사이를 비워
같은 가격이 양쪽에 들어가는 편향 제거) · 전후반 분할 안정성 · 분위 스프레드를 왕복비용과 비교.

국내/글로벌 분해는 예측이 아니라 정의상 성립하는 항등식이라 검정 대상이 아니다.

## 구조

```
GitHub Actions (5분)                     브라우저 (정적 페이지)
  ├ /ticker/all       1회                  ├ board.json    기준가·이름·환율·분해 스냅샷
  ├ /candles          120회 (10req/s)      ├ 업비트 WS     초 단위 체결가
  ├ 바이낸스 4h/1d 윈도우 티커  2회          └ 바이낸스 REST 60초마다 글로벌 4h 변동
  └ board.json → data 브랜치 force-push
```

### 왜 캔들 수집이 브라우저에 없나

업비트 REST는 **Origin 헤더 유무로 쿼터 그룹이 갈린다.** 실측:

| 호출 주체 | 쿼터 그룹 | 한도 | 실측 |
|---|---|---|---|
| 브라우저 (Origin 있음) | `group=origin` | 사실상 초당 1회 | 1회 성공 후 **연속 429** |
| Actions/서버 (Origin 없음) | `group=candles` | 600/분 · 10/초 | 15회 연속 200 |

그래서 120종목 캔들 수집은 서버에서만 가능하다. 반면 **업비트 WebSocket과 바이낸스 REST는
둘 다 CORS가 열려 있어** 브라우저에서 직접 쓴다 — 이게 정적 사이트로 실시간이 되는 이유다.

### 창(window) 맞추기

업비트 `signed_change_rate`는 **전일 종가 대비**이고 바이낸스 `24hr`은 **롤링 24시간**이다.
그대로 빼면 안 된다. 그래서 스캐너가 4시간/24시간 전 기준가를 캔들에서 뽑아 `board.json`에
싣고, 브라우저는 그 기준가와 실시간 체결가로 업비트 수익률을 다시 계산해 바이낸스의 같은
창(`windowSize=4h`)과 맞춘다.

## 배포

1. GitHub 저장소로 push (public 권장 — Actions 무료 무제한)
2. **Settings → Pages** → `Deploy from a branch`, `main` / `/docs`
3. **Settings → Actions → General** → Workflow permissions: `Read and write`
4. Actions 탭에서 `scan` 1회 수동 실행 → `data` 브랜치 생성 확인
5. [docs/config.js](docs/config.js)의 `BOARD_DATA_URL`을 본인 저장소 raw URL로 교체

5번을 건너뛰어도 커밋된 `docs/data/board.json`으로 동작하며, raw URL 실패 시 자동 폴백한다.
`data` 브랜치는 매번 히스토리 없는 단일 커밋으로 force-push 하므로 저장소가 불어나지 않는다.

## 로컬 실행

```bash
python3 tools/scan.py            # docs/data/board.json 생성 (약 60초)
python3 -m http.server 8899 --directory docs
open http://127.0.0.1:8899
```

의존성 없음 (Python 표준 라이브러리만).

## 알아둘 것

- Actions cron은 5분이 최소 간격이고 혼잡 시 수 분 밀린다. 다만 화면의 가격과 분해는
  WebSocket + 바이낸스 60초 갱신이라 실제로는 훨씬 빠르다.
- 60일간 저장소 활동이 없으면 GitHub가 스케줄 워크플로를 자동 비활성화한다.
- 업비트와 바이낸스에 티커가 같아도 다른 토큰인 경우가 있다(예: DATA에서 김프 +23,776% 관측).
  `|김프| > 5%`면 분해에서 제외한다.
- USDT/원 환율은 업비트 KRW-USDT 체결가를 쓴다. 호가 단위(1원 ≈ 0.07%)만큼 잡음이 섞인다.

## 고지

공개 시세를 기계적으로 가공한 **정보 제공** 화면이며, 예측이 아니라 이미 일어난 변동의 분해다.
투자 자문·권유가 아니고 매매 판단과 결과의 책임은 이용자 본인에게 있다.
불특정 다수에게 공개 운영할 경우 국내법상 유사투자자문업 신고 대상이 될 수 있다.
